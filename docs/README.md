# Tài liệu nộp bài

Đặt hai file PDF vào thư mục này trước khi nén ZIP:

- Báo cáo bài tập lớn.
- Slide thuyết trình (bản dùng khi trình bày trực tiếp hoặc trong video).

Nhóm thuyết trình bằng video: dán link YouTube (unlisted) hoặc Google Drive lên trang bìa báo cáo. Mọi thành viên phải xuất hiện và trình bày.
