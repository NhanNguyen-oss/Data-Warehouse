# Dữ liệu mẫu

Thư mục này nộp cùng bài tập lớn CO4031.

- `raw/`: file nguồn (CSV hoặc bản trích đủ để chấm bài chạy lại ETL). Pipeline đọc `raw/source.csv` nếu file tồn tại.
- `processed/`: file sinh ra sau ETL (`fact_event.csv` khi chạy khung mặc định). Không sửa tay file này.

Nếu bộ dữ liệu đầy đủ quá lớn cho ZIP hoặc GitHub, để bản mẫu nhỏ ở đây và ghi link Google Drive (quyền xem) vào mục này. Không đưa dữ liệu cá nhân hoặc dữ liệu doanh nghiệp khi chưa được phép.
